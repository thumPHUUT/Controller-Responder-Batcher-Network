# Controller-Responder-Batcher-Network

Controller-Responder Batcher networks have been adopted in digital circuits implementing the fourth generation wireless communication standard (i.e., LTE) which are used to rank N distinct natural numbers in ascending order.
This network is made to rank 8 numbers and was developed as part of an accredited university class project. Due to technical limitations for running this software (this was developped on university hardware), running this program on the intended Altera Quartus II FPGA board may not be accessible/possible.

Written in VHDL on Intel Quartus and tested/modeled in ModelSim
